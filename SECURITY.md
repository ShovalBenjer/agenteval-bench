# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by emailing [security@shovalbenjer.com](mailto:security@shovalbenjer.com).

Please include:
- A description of the vulnerability
- Steps to reproduce
- Any relevant logs or screenshots

We will acknowledge receipt within 48 hours and provide a detailed response within 7 days.
